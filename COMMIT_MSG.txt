IEC61850ANALYZER v0.6.5 - IED Simulator: GOOSE of the simulated IED

New tab GOOSE in the IED Simulator: the GOOSE control blocks of the
simulated IED (CID) are published with the values of its data model.

- Same values and quality as the MMS reports (one quality per signal /
  structure): a value or quality set by hand -> stNum + 1 and fast
  retransmission MinTime -> MaxTime, TAL = 2 x interval
- Per GoCB: Publish (GoEna, also visible to SCADA over MMS), Simulation
  (ON by default, OFF only after a warning), NdsCom; button stNum + 1
- MAC / APPID / VLAN / priority / MinTime / MaxTime from the CID (GSE),
  network adapter as in the GOOSE Publisher
- Warning: the real IED must be disconnected (same MAC / APPID / GoID)

Adapters...: names as in Windows Network Connections ('Ethernet 5 -
Realtek USB GbE Family Controller - IP 172.16.1.32 (+10)'); virtual
adapters (WAN Miniport, Wi-Fi Direct, loopback ...) hidden, checkbox
'Show virtual adapters'.

Tested: frames of the F60 CID (GoCB BAY, BBP) decoded by the own GOOSE
decoder - simulation flag, data set values, new state after a change.
