IEC61850ANALYZER v0.6.4 - MMS Active: export to Excel

Button 'Export to Excel...' on the tab MMS / Active: one .xlsx file with
the IED read online.

- Info: IED, IP, identity (vendor / model / revision), CID, date, PC,
  program version
- Model: every attribute - LD, LN, FC, DO / DA, type, value at the time
  of the export, 61850 reference (big LNs of GE UR read level by level)
- Data sets: data set, member number, member (61850 and MMS), FC
- Control blocks: RCB / GoCB with state (free / reserved / in use by),
  RptID / GoID, DatSet, ConfRev, TrgOps, OptFlds, IntgPd, BufTm, Owner,
  MAC, APPID, VLAN
- Compare with CID: findings (when the CID is loaded)
- Header frozen, filter in every column
- Own xlsx writer (xlsx_lite.py): no extra library, requirements.txt
  unchanged; checked with Excel format readers (openpyxl, LibreOffice)
