IEC61850ANALYZER v0.5.0 - MMS Report test (RCB test against the CID)

New sub tab MMS / Report test: the reports of one IED are checked
against its CID while SCADA (or a capture file) delivers them.

- CID check: RptID -> ReportControl, DatSet, ConfRev, number of data set
  entries, data references, types of the values (DataTypeTemplates),
  reasons allowed by TrgOps, OptFlds against OptFields, reports of RCBs
  that are not in the CID
- Coverage of every signal of the report data sets: data change,
  quality change, data update, integrity, general interrogation (first
  time, count), last value. Possible reasons = TrgOps of the RCB and the
  trigger options of the attribute in the CID, else n/a
- BOOLEAN / Dbpos: data change needs both states (TRUE / FALSE, on / off);
  the minimum time between two opposite states is shown
- Required for "completed" (default): data change, GI, integrity;
  quality change and data update optional. Counted per data set (any
  RCB instance)
- "RCB test completed - all signals verified - <date time>"
- Save / open the test (.json, auto save every 30 s), export CSV (Excel)
- RCBs without a data set in the CID (data sets configured in the IED,
  e.g. GE UR): tested with the data set seen in the traffic
